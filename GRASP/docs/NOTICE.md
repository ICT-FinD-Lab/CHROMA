# Attribution

GRASP is introduced in *Differentially Private Graph Reconstruction Defense
with Structured Perturbation*, [KDD 2025](https://doi.org/10.1145/3711896.3736992).
The original implementation is available at
[ZhiyuZone/GRASP](https://github.com/ZhiyuZone/GRASP).

The GNN implementation uses PyTorch and PyTorch Geometric. Dataset loading uses
PyTorch Geometric and OGB; graph coloring uses NetworkX. The logger is adapted
from [OGB](https://github.com/snap-stanford/ogb). These projects retain their
respective licenses and attribution requirements.
